# Lung Cancer Classification - Streamlit App

A simple Streamlit application that loads the five classification models and preprocessing objects saved by `ML_Assignment_2.ipynb`.

## 1. Generate the model files

Run the final model-saving cell in your notebook. It should create:

```text
saved_models/
├── logistic_regression.pkl
├── decision_tree.pkl
├── knn.pkl
├── naive_bayes.pkl
├── svm.pkl
├── feature_scaler.pkl
└── label_encoders.pkl
```

Copy this `saved_models` folder beside `app.py`.

Also copy the `test_data.csv` file generated by your notebook into this project folder. The app lets you upload it; it does not automatically train or modify any models.

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

For deployment, use the same scikit-learn version that was used to train and save the models. Pickle/joblib model files are not guaranteed to be compatible across different scikit-learn versions.

## 3. Run the application

```bash
streamlit run app.py
```

## 4. Upload data

The CSV must contain the 15 input feature columns:

`GENDER`, `AGE`, `SMOKING`, `YELLOW_FINGERS`, `ANXIETY`, `PEER_PRESSURE`, `CHRONIC DISEASE`, `FATIGUE`, `ALLERGY`, `WHEEZING`, `ALCOHOL CONSUMING`, `COUGHING`, `SHORTNESS OF BREATH`, `SWALLOWING DIFFICULTY`, `CHEST PAIN`.

Include `LUNG_CANCER` (`YES`/`NO`) to view evaluation metrics, confusion matrix, and classification report. If the target column is absent, the app displays predictions only.

## Notes

- The app does not train models.
- It reuses the label encoders and scaler saved by the notebook.
- Keep the `saved_models` folder beside `app.py`.
- This is an academic classification demonstration, not a medical diagnostic tool.
